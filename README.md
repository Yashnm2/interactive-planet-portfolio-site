# Recruiter Portfolio v2

An interactive five-scene portfolio built with React, Three.js, and React Three Fiber.

## Run locally

```bash
npm install
npm run dev
```

## Personalize before sharing broadly

Edit `site-src/App.jsx` to replace:

- `Y/N` with your initials or wordmark
- `you@example.com` with your email
- the Singapore location if needed
- the three signal descriptions with real projects and outcomes
- the disabled résumé button with your résumé URL

The five visual concept frames are in `concepts/`.
